Routine colors

  • Push lime · Pull cyan · Legs orange.
  • Color only marks a routine. It's never used for decoration, and text on it stays dark.
  • Running workout: in the colored direction the Start button becomes a white timer, so it never clashes with Legs orange. In the poster-only direction it stays orange.
  • The body weight trend stays lime in every routine, since it isn't tied to one.

Tab icons

  • Set A: Today is a sun on the horizon, Plan a calendar with workout dots, Progress a line rising to a peak, Exercises a barbell with plates. Thicker strokes, filled when selected.
  • Set B: solid shapes on the same grid, uppercase condensed labels to match the titles, and a short colored underline under the current tab.
  • Both keep text labels. The current tab never relies on color alone (A fills, B underlines).
