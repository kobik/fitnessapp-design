openGym redesign · Round 1d · Today restructured

One system, three platforms

What changed: today's workout comes first, with Start right under it. The week strip and streak share one card. Body weight is one slim row (the full chart moves to Progress). Check in only shows on a workout day before you start. The tabs match the real app again: Today · Plan · Start · Progress · Exercises. The middle Start button is outlined until a workout runs, then it turns into an orange live timer.

System 1b (Apple-style structure, bold condensed titles and numbers), adapted for iOS, Android and the web. Colors, type, shapes and content are the same everywhere. Only navigation, body font, sheets and the wide-screen layout change, so each platform feels native. Each screen below is live: pick a day, start the workout, log a weigh-in.
